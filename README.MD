# 🐍 Python & Data Science Portfolio

Bu anbar (repository) **Python backend**, **Riyazi Modelləşdirmə**, **Data Analytics** və **Data Science** istiqamətlərində işlədiyim praktiki layihələri, Jupyter Notebook tədqiqatlarını və tətbiqi kod resurslarını əhatə edir.

---

## 🛠️ İstifadə Olunan Texnologiyalar və Kitabxanalar

Layihələrdə geniş tətbiq olunan və davamlı olaraq istifadə etdiyim əsas alətlər:

* **Data Analitikası və Emalı:** `Pandas`, `NumPy`
* **Riyazi Modelləşdirmə və Hesablamalar:** Jupyter Notebooks, Hesablama Alqoritmləri
* **Fayl və Sənəd Emalı:** `PyPDF2` / `pdfplumber` (PDF məlumatlarının avtomatlaşdırılmış emalı və analizi)
* **Backend Development:** `Python`, `Flask`
* **Versiya İdarəetməsi:** `Git`, `GitHub`

---

##  Əsas Mövzular və Fayllar

* 📊 **Data Science & Analytics:** Məlumatların təmizlənməsi, analizi və vizualizasiyası.
* 🪐 **Riyazi Modelləşdirmə:** Məkan/koordinat hesablamaları və optimallaşdırma layihələri.
* 🐍 **Python Əsasları və Data Strukturları:** Bütün baza tipləri (`List`, `Bool`, `Integer`, `String`) üzrə dərindən tətbiqi tapşırıqlar.

*Bu layihələr davamlı olaraq yenilənir və yeni Data Science / Python həlləri ilə zənginləşdirilir.*
